# Jobs To Be Done

1. **When evaluating a new opportunity**, help me understand whether it fits our strategy so I can decide where to spend diligence time.
2. **When preparing for investment committee**, help me consolidate thesis, returns, risks and unresolved diligence so decision-makers can act confidently.
3. **When monitoring an investment**, help me compare actual performance with the approved case so I can identify meaningful deviations early.
4. **When a material deviation occurs**, help me assign, investigate and document an action so the portfolio team has accountability and audit history.
