# Current-State Workflow

## Working hypothesis
A typical deal requires information from CRM/deal tools, spreadsheets, data rooms, market-data vendors, financial models, email and presentation materials.

| Stage | User | Inputs | Decision/output | Potential friction |
|---|---|---|---|---|
| Screening | Associate | teaser, market data | pursue/reject | inconsistent criteria |
| Diligence | Deal team | data room, experts, models | validated thesis | task/document fragmentation |
| IC prep | Associate/VP | model, risks, memo | recommendation | manual synthesis |
| IC | Committee | memo, model | approve/reject | context scattered |
| Monitoring | Portfolio team | monthly/quarterly KPIs | intervention | original assumptions not linked |
| Review | PM/IC | actual vs plan | action/re-underwrite | exception detection can be manual |

This workflow is a hypothesis to support product design, not a claim about any specific firm.
