# Go / No-Go

## Go
- critical UAT passed
- baseline/actual reconciliation signed off
- SSO/RBAC verified
- monitoring and support rota active
- rollback rehearsed
- user communications ready

## No-Go triggers
- incorrect investment/metric mapping
- missing audit history
- unresolved Sev-1/Sev-2
- unstable critical data feed
- inability to restore previous release
