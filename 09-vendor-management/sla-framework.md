# Vendor SLA Framework

- Availability: >=99.9% for critical data API
- Data delivery: by agreed reporting cutoff
- Incident acknowledgment: P1 within 30 minutes
- Incident updates: hourly for P1
- Recovery target: contract-specific
- Data-quality reconciliation: defined error threshold
- Change notice: advance notice for breaking schema/API changes
- Security: annual assurance documentation and breach-notification terms
- Service credits: tied to repeated material breaches
