# Build vs Buy

## Decision
**Build the thesis/exception workflow; integrate commodity capabilities.**

| Capability | Build/Buy | Rationale |
|---|---|---|
| Thesis baseline/versioning | Build | differentiating workflow |
| Variance/exception engine | Build | core product logic |
| Portfolio UI | Build | core experience |
| Market data | Buy | expensive to reproduce |
| SSO | Integrate | enterprise commodity |
| Notifications | Integrate | commodity |
| Document storage | Integrate | existing enterprise systems |

## Evaluation dimensions
Functional fit, API quality, data coverage, security, SLA, implementation effort, total cost, roadmap alignment, exit risk.
