# User Flows

## Approve thesis baseline
Deal workspace → review thesis metrics → validate source/definition → IC approves → baseline frozen → investment created.

## Monitor exception
Portfolio overview → exception queue → open investment → compare target/actual/history → review source freshness → assign owner → document explanation → create action → resolve/re-underwrite.

## Re-underwrite
Material change → propose revised assumption → retain original baseline → capture rationale → approval → new version becomes active.
