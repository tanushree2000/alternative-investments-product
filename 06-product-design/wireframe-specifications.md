# Wireframe Specifications

## Screen 1: Portfolio Overview
KPI cards: active investments, thesis-linked coverage, open P0/P1 exceptions, stale data sources.  
Table: company, sector, investment date, thesis status, exception count, latest review.

## Screen 2: Deal Workspace
Header: deal stage, owner, sector, size.  
Tabs: Thesis | Diligence | Financial Case | Risks | IC Decision.  
Primary action: Submit for IC review.

## Screen 3: Investment Committee Review
Decision summary, base/upside/downside returns, top assumptions, unresolved diligence, risks, approve/reject/request work.

## Screen 4: Thesis Monitor
For each metric: approved target, actual, variance, trend, threshold, status, source freshness.  
Right rail: exceptions, owner, comments, actions.

## Screen 5: Exception Detail
Severity, breached rule, target vs actual, history, source, explanation, owner, due date, remediation, resolution.
