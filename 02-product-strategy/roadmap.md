# Outcome Roadmap

## Release 1 — Establish the baseline
**Outcome:** approved thesis can be stored and governed.
- Deal/investment record
- thesis metrics and milestones
- IC approval snapshot
- roles and audit trail

## Release 2 — Monitor reality
**Outcome:** actual KPI data is mapped to the approved case.
- data ingestion
- KPI mapping
- variance calculation
- portfolio summary

## Release 3 — Act on exceptions
**Outcome:** material deviations become accountable workflows.
- threshold rules
- exception queue
- owner/status/comments
- notifications

## Release 4 — Scale intelligence
**Outcome:** improve comparison and portfolio learning.
- benchmarks
- scenario overlays
- advanced analytics
