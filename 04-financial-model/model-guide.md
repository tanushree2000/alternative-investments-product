# Financial Model Guide

The workbook is a **synthetic, simplified LBO-style model**, not an investment recommendation.

## Inputs
Entry revenue, EBITDA margin, revenue growth, entry/exit multiples, leverage, interest rate, debt paydown and holding period.

## Outputs
Entry EV/equity, Year 5 EBITDA, exit EV/equity, MOIC and annualized IRR.

## Interview concepts
- **Enterprise Value:** value of operations before net debt.
- **MOIC:** exit equity value ÷ entry equity invested.
- **IRR:** annualized return implied by MOIC and holding period in this simplified single-entry/single-exit case.
- **Sensitivity:** shows how return changes with operating growth and exit multiple.

All assumptions are synthetic and editable.
