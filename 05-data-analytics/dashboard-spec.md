# Dashboard Specification

## Page 1 — Executive Portfolio
Cards: active investments, invested capital, P0/P1 exceptions, thesis-linked coverage.
Charts: exceptions by sector; target vs actual growth; portfolio table sorted by severity.

## Page 2 — Deal Pipeline
Funnel: stage counts and value.
Bars: average days in stage by sector/owner.
Table: aging deals with screening score.

## Page 3 — Thesis Monitor
Filters: company, sector, severity.
Visual: target vs actual revenue growth and EBITDA margin.
Detail table: variance, threshold, severity, source freshness.

Use `synthetic-deals.csv` and `portfolio-performance.csv` in Tableau or Power BI.
